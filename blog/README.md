# ブログ用サービス案内ボックス

はてなブログの記事末尾に挿入する、たすかるワークのサービス案内HTMLです。  
サイト（taskall.work）と同じカラー・トーンで統一しています。

## ファイル一覧

| ファイル | 用途 |
|---|---|
| `embed/service-box.html` | 汎用版（どの記事でも使える） |
| `embed/service-box-excel.html` | エクセル関連記事向け |
| `embed/service-box-word.html` | ワード関連記事向け |
| `preview.html` | ローカルでの見た目確認用 |

## はてなブログへの挿入方法

1. 記事編集画面を開く
2. 右上のメニューから **「HTML編集」** を選ぶ
3. 記事本文の**末尾**に、使いたいファイルの中身をコピー＆ペースト
4. 先頭の `<!-- ... -->` コメント行は削除しても残してもOK
5. プレビューで表示を確認して公開

### 記事テーマ別の使い分け

- エクセルの関数・表作成など → `service-box-excel.html`
- 報告書・議事録・文書作成など → `service-box-word.html`
- 事務全般・データ入力・その他 → `service-box.html`

## ローカルでプレビュー

```bash
cd blog
python3 -m http.server 8080
```

ブラウザで http://localhost:8080/preview.html を開いてください。

## カスタマイズのヒント

- **見出し**（太字の1行目）だけ記事内容に合わせて書き換えると自然です
- **バッジ**（見積もり無料など）は記事に合わせて増減できます
- リンク先は変更しないでください（お見積もりフォーム・各サービスページ）
